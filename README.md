# Worklazy Tools

**귀찮은 파일 작업은 도구에게 맡기세요.**

여러 엑셀 파일을 하나로 모으고, PDF에서 필요한 페이지만 꺼내고, 수정 전후 문서의 차이를 확인하는 일. Worklazy Tools는 이런 반복 작업을 브라우저에서 처리하는 무료 업무 도구 모음입니다.

프로그램을 따로 설치하거나 회원가입을 할 필요가 없습니다. 필요한 도구를 열고 파일을 선택하거나 내용을 입력한 뒤, 결과를 확인하고 저장하세요.

**[바로 사용하기](https://worklazy.net/ko/) · [전체 도구 보기](https://worklazy.net/ko/tools/) · [문의·오류 제보](https://github.com/Fentanest/WorklazyTools/issues)**

> 작업 파일과 입력한 파일 암호는 외부 파일 처리 서버로 보내지 않습니다. 일부 도구는 실행에 필요한 프로그램 파일을 내려받지만, 선택한 문서와 결과는 브라우저 안에서 처리합니다.

## 이렇게 사용하세요

1. **도구를 고릅니다.** 사이드바나 전체 도구 목록에서 필요한 기능을 찾으세요.
2. **파일이나 내용을 넣습니다.** 파일을 끌어 놓거나 선택하고, 텍스트·계산 도구에서는 내용을 직접 입력하세요.
3. **결과를 확인하고 저장합니다.** 필요한 옵션을 고른 뒤 작업을 실행하세요. 결과를 살펴보고 다운로드하거나 복사하면 됩니다.

어떤 파일을 준비해야 할지 모르겠다면 각 도구의 사용 안내와 자주 묻는 질문을 확인하세요. 지원하는 파일 형식과 저장 방식도 함께 안내합니다.

## 사용할 수 있는 도구

### 엑셀·표

파일을 모으고, 차이를 찾고, 필요한 데이터만 정리합니다.

| 도구 | 할 수 있는 일 |
| --- | --- |
| **[엑셀 병합](https://worklazy.net/ko/tools/excel-merger/)** | 여러 엑셀·CSV 파일을 하나로 합칩니다. 시트를 각각 모으거나, 표를 아래로 이어 붙이거나, 옆으로 붙일 수 있습니다. |
| **[엑셀 비교](https://worklazy.net/ko/tools/excel-compare/)** | 두 파일의 값·수식·서식 차이를 찾습니다. 행과 열의 위치를 맞추거나 사번·거래번호 같은 기준 항목으로 연결해 비교하고, 결과를 엑셀 보고서로 받습니다. |
| **[엑셀 정리](https://worklazy.net/ko/tools/excel-cleaner/)** | 빈 행·열, 중복, 불필요한 공백 등을 정리합니다. 선택한 규칙을 순서대로 적용해 새 엑셀·CSV 파일과 처리 보고서를 만듭니다. |
| **[표 데이터 변환](https://worklazy.net/ko/tools/data-converter/)** | CSV·JSON·HTML 표를 서로 바꿉니다. 다른 프로그램이나 웹페이지에서 사용할 수 있도록 변환한 뒤 파일로 저장하거나 복사합니다. |

**엑셀 병합**에서는 파일마다 포함할 시트를 고르고, 앞에서 몇 개 또는 몇 번째 시트를 가져올지도 정할 수 있습니다. 불필요한 끝 여백을 줄이거나 제외할 행·열을 설정하고, 입력 형식에 맞는 수식·서식 보존 옵션을 선택하세요. 결과는 XLSX로 저장되며 XLSM 매크로는 보존되지 않습니다.

**엑셀 비교**에서는 자료에 맞는 비교 기준을 고르는 것이 중요합니다. 수정 전후 표는 행·열을 맞춰 비교하고, 순서가 다른 명단은 사번 같은 기준 항목으로 연결하세요. 정산 자료는 금액·날짜·거래처를 맞추는 거래 대사 기능을 사용할 수 있습니다. 비교 가능한 항목은 파일 형식에 따라 다릅니다.

### 문서·PDF

문서를 만들거나 수정하고, 변경 내용을 확인하거나 필요한 형식으로 저장합니다.

| 도구 | 할 수 있는 일 |
| --- | --- |
| **[PDF 도구](https://worklazy.net/ko/tools/pdf-editor/)** | 여러 PDF를 합치고 페이지 순서를 바꾸거나 필요한 페이지만 저장합니다. 이미지·문서 변환, 스캔한 글자 읽기, 페이지 번호·워터마크 추가도 제공합니다. |
| **[워드 일괄 생성](https://worklazy.net/ko/tools/document-generator/)** | 워드 양식에 엑셀·CSV 목록을 채워 사람별·항목별 문서를 한 번에 만듭니다. 직원별 안내문이나 고객별 확인서처럼 같은 양식을 반복해서 쓸 때 유용합니다. |
| **[문서 비교](https://worklazy.net/ko/tools/document-compare/)** | 워드 또는 한글 문서의 수정 전후를 비교합니다. 본문·표·서식의 변경을 좌우 화면에서 확인하고 엑셀 보고서로 저장할 수 있습니다. |
| **[PDF 비교](https://worklazy.net/ko/tools/pdf-compare/)** | 수정 전후 PDF를 페이지별로 비교합니다. 두 페이지를 나란히 보거나 차이를 겹쳐 확인하고, PDF에서 읽어 낸 글자 내용도 비교합니다. |
| **[한글 문서 편집](https://worklazy.net/ko/tools/hwp-editor/)** | HWP·HWPX 문서를 브라우저에서 열어 글·표·서식 등을 편집하고 다시 저장합니다. 문서 편집에는 사이트에 포함된 rhwp 편집기를 사용합니다. |
| **[오피스 편집기](https://worklazy.net/ko/tools/office-editor/)** | 워드 문서, 엑셀 시트, 프레젠테이션을 LibreOffice 기반 화면에서 열고 편집합니다. DOCX·DOC·ODT, XLSX·XLS·ODS, PPTX·PPT·ODP 파일을 다룹니다. |

**PDF 도구의 주요 작업**

- **페이지 정리:** 합치기, 순서 변경, 삭제, 회전, 필요한 페이지만 저장하거나 여러 파일로 나누기.
- **형식 바꾸기:** 이미지를 PDF로 만들기, PDF 페이지를 PNG·JPG로 저장하기, PDF 내용을 DOCX·XLSX·TXT로 변환하기.
- **스캔 문서 활용:** 한국어·영어 글자를 읽어 문서로 저장하거나 검색 가능한 PDF 만들기. 이미지 속 글자를 읽는 기능을 OCR이라고 합니다.
- **문서 마무리:** 페이지 번호, 머리글·바닥글, 글자·이미지 워터마크, 도장·서명 이미지 넣기.

PDF를 워드나 엑셀로 바꾸면 읽기 순서·표 배치가 원본과 다를 수 있고, OCR에는 오인식이 있을 수 있습니다. 도장·서명 이미지 추가는 인증서 기반 전자서명을 만드는 기능이 아닙니다.

**문서 비교는 같은 계열끼리 사용합니다.** 워드 파일은 워드 파일과, 한글 파일은 한글 파일과 짝지어 주세요. 두 파일이 모두 DOCX이면 Word에서 확인할 수 있는 변경 내용 추적 문서도 만들 수 있습니다. 기존의 Word 비교와 HWP 비교는 문서 비교 메뉴에서 함께 사용할 수 있습니다.

### 이미지·영상·오디오

사진을 다듬고, 영상의 필요한 구간을 남기고, 녹음한 소리를 편집합니다. 화면에 따라 이미지·비디오·오디오 **스튜디오**라는 이름으로 표시됩니다.

| 도구 | 할 수 있는 일 |
| --- | --- |
| **[이미지 편집](https://worklazy.net/ko/tools/image-studio/)** | 사진 크기 조절·자르기·회전·보정과 선택 영역 모자이크·블러를 적용합니다. 글자·스티커·도형·그리기를 더하고, 여러 장의 일괄 편집·콜라주·GIF도 만듭니다. |
| **[영상 편집·변환](https://worklazy.net/ko/tools/video-studio/)** | 필요한 구간을 자르고 여러 영상을 이어 붙이거나 파일 형식을 바꿉니다. 영상을 그룹으로 나눠 비교 재생하고, GIF를 만들거나 소리만 MP3·AAC로 저장할 수 있습니다. |
| **[오디오 편집](https://worklazy.net/ko/tools/audio-studio/)** | 소리의 파형을 보면서 구간을 선택해 자르기·복사·붙여넣기·음소거를 합니다. 음높이와 음색을 바꾸고 WAV·MP3로 저장할 수 있습니다. |

이미지 편집에서는 클립보드의 그림을 붙여 넣거나, 여러 이미지에 같은 크기·워터마크 설정을 적용할 수 있습니다. 세로·가로 이어 붙이기와 격자 콜라주도 제공합니다. PNG·WebP는 투명 배경을 유지할 수 있고, JPG는 흰색 배경으로 저장합니다.

영상은 최대 10개 그룹으로 나눠 구간과 출력 방식을 정할 수 있습니다. 같은 그룹의 영상을 함께 재생하거나 한 그룹의 구간 설정을 다른 그룹에도 적용하세요. 전체 영상을 다시 변환하지 않고 자르는 빠른 방식도 제공하며, 완성된 파일은 개별 다운로드 또는 선택한 결과의 ZIP 묶음으로 받을 수 있습니다.

영상에서 추출한 MP3·AAC는 오디오 편집기로 보내 작업을 이어갈 수 있습니다. 오디오 편집은 MP3·WAV·M4A·AAC·OGG를 대상으로 하며, 재생 반복·파형 확대와 실행 취소·다시 실행도 지원합니다. 열 수 있는 음성 형식은 기기와 브라우저에 따라 달라질 수 있습니다.

### 텍스트·코드

복사해 온 글을 정리하고, 나뉜 내용을 합치거나, 코드의 형식을 다듬습니다.

| 도구 | 할 수 있는 일 |
| --- | --- |
| **[텍스트 병합](https://worklazy.net/ko/tools/text-merger/)** | 직접 입력한 글과 TXT 파일을 원하는 순서로 합칩니다. 파일 사이에 안내 문장을 넣거나 줄바꿈·공백·구분 문자를 지정하고, 결과를 복사하거나 TXT로 저장합니다. |
| **[텍스트 정리](https://worklazy.net/ko/tools/text-tools/)** | 공백·줄바꿈·중복 줄을 정리하고 대소문자나 단어 연결 방식을 바꿉니다. 한국어 문장을 다듬을 때 참고할 수 있는 검사도 제공합니다. |
| **[코드 포맷터](https://worklazy.net/ko/tools/text-formatter/)** | JSON·SQL·XML의 들여쓰기를 정리하거나 한 줄로 줄입니다. JSON·XML의 문법 오류를 확인할 수 있으며, 입력한 SQL을 데이터베이스에서 실행하지는 않습니다. |

한국어 문장 검사는 정해진 규칙에 따른 참고 안내입니다. 문맥과 의미를 모두 판단하는 교정 기능은 아니므로 최종 문장은 직접 확인해 주세요.

| **[비밀번호 생성기](https://worklazy.net/ko/tools/security-tools/)** | 길이와 사용할 문자를 골라 비밀번호를 만듭니다. 보안용 난수를 사용하며, 입력한 비밀번호의 패턴과 추측 난이도도 확인할 수 있습니다. |
| **[QR 생성·읽기](https://worklazy.net/ko/tools/qr-studio/)** | 링크·텍스트를 QR 코드로 만들거나 카메라·사진에서 읽습니다. 표 파일의 각 행으로 QR 코드를 일괄 생성하고 PNG·ZIP·인쇄용 라벨 PDF로 저장할 수 있습니다. |

**개인정보 가리기는 저장 방식에 주의하세요.** PDF의 모든 페이지를 이미지로 바꿔 새 PDF를 만듭니다. 가리지 않은 페이지도 글자 검색·선택·복사, 기존 전자서명·입력 양식·링크가 유지되지 않습니다. 중요한 원본은 따로 보관하고, 공유할 새 파일의 전체 페이지와 파일 이름을 다시 확인해 주세요.

사진 메타데이터 제거는 JPG·PNG·WebP를 지원하며 HEIC·HEIF는 지원하지 않습니다. 여러 사진의 결과는 ZIP으로 받을 수 있습니다. QR에는 중앙 로고를 넣을 수 있지만, 읽은 QR의 링크가 안전한지까지 검사해 주지는 않습니다. 비밀번호의 강도와 해독 시간 역시 비교를 위한 추정값이지 보안을 보장하는 수치는 아닙니다.

## 워드 일괄 생성은 이렇게 동작해요

같은 안내문에서 이름과 부서만 바꿔 여러 문서를 만들어야 한다면, 하나씩 복사할 필요가 없습니다. **DOCX 양식 한 개와 XLSX·CSV 목록을 준비하세요.**

워드 양식에서 바뀔 부분을 중괄호 한 쌍으로 표시합니다.

```text
{이름} 님, 안녕하세요.
소속 부서: {부서}
교육 일정을 확인해 주세요.
```

엑셀에는 다음처럼 목록을 적습니다. 아래 이름과 부서는 사용 방법을 설명하기 위한 예시입니다.

| 이름 | 부서 |
| --- | --- |
| 김민수 | 영업팀 |
| 이서연 | 인사팀 |

양식과 목록을 선택하고 항목을 연결하면, **김민수 님의 안내문과 이서연 님의 안내문이 각각 DOCX 파일로 만들어집니다.** 엑셀의 열 이름이 양식과 다르더라도 화면에서 연결할 항목 이름을 지정할 수 있습니다.

전체 문서를 만들기 전에 한 행으로 샘플을 만들어 글자·날짜·금액과 배치를 확인하세요. 결과 파일 이름 규칙도 직접 정할 수 있고, 완성된 문서는 개별 파일이나 ZIP으로 받을 수 있습니다.

이 기능은 **준비된 양식에 값을 채우는 방식**입니다. 글을 새로 쓰는 AI나 이메일 발송 기능은 아닙니다. 반복·조건문·이미지 삽입 항목, 매크로 양식과 암호 문서는 지원하지 않습니다.

## 파일은 어떻게 처리하나요?

### 작업 파일은 브라우저 안에서 처리합니다

선택한 문서·사진·영상·오디오와 입력한 파일 암호는 외부 파일 처리 서버로 보내지 않습니다. 텍스트·급여·날짜·비밀번호 입력도 브라우저에서 처리합니다.

웹사이트와 도구를 실행하려면 프로그램 파일을 내려받는 네트워크 요청은 필요할 수 있습니다. 방문 분석·광고 역시 사용자의 동의 설정과 페이지별 정책에 따라 별도로 동작합니다. **이런 요청과 작업 파일 업로드는 서로 다릅니다.** 자세한 내용은 [개인정보처리방침](https://worklazy.net/ko/privacy/)을 확인하세요.

### 결과는 작업이 끝나면 저장해 주세요

일반적인 작업 상태는 새로고침하거나 탭을 닫으면 사라집니다. 필요한 결과는 먼저 다운로드하거나 복사해 두세요.

다만 일부 기능은 브라우저 저장 공간을 사용합니다. 한글 편집기는 복구용 초안을 저장할 수 있고, 오피스 편집기는 화면 사이에 파일을 전달할 때 잠시 보관한 뒤 가져오면 삭제합니다. 편집기에 필요한 프로그램 파일은 다음 실행을 위해 캐시에 남을 수 있습니다.

공용 PC에서는 다운로드한 파일과 브라우저에 남은 초안·사이트 데이터를 필요에 따라 정리하세요. 원본과 결과가 중요한 자료라면 따로 백업해 두는 것이 좋습니다.

## 사용 전에 알아두세요

**첫 실행은 준비 시간이 필요할 수 있습니다.** 오피스 편집기·영상 처리·OCR 등은 필요한 프로그램 파일을 내려받습니다. 처음 접속하거나 필요한 파일이 캐시에 없으면 인터넷 연결이 필요합니다. 오피스 편집기는 첫 준비에 수백 MB의 저장 공간을 사용할 수 있습니다.

**파일이 크면 기기 성능의 영향을 받습니다.** 긴 영상, 고해상도 이미지, 페이지가 많은 PDF, 큰 표는 메모리와 처리 시간을 많이 사용할 수 있습니다. 먼저 적은 파일이나 짧은 구간으로 확인하고 작업량을 늘려 보세요.

**지원 여부는 파일과 브라우저에 따라 다릅니다.** 암호가 걸린 파일의 지원 범위는 도구마다 다릅니다. PDF 도구와 PDF 비교에는 암호를 해제한 사본을 사용하세요. 카메라나 일부 편집 기능은 보안 연결·권한·브라우저 기능이 필요하므로 화면의 안내를 확인해 주세요.

**원본과 같은 결과를 보장하지는 않습니다.** 복잡한 문서 서식, 차트, 수식, 글꼴이나 고급 개체는 원래 프로그램과 다르게 처리될 수 있습니다. 오피스 편집기는 Microsoft Office의 공식 웹 버전이 아니라 LibreOffice 기반 편집기입니다. 중요한 결과는 실제 사용할 프로그램에서도 확인하세요.
