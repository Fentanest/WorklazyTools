# Worklazy Tools

귀찮고 반복적인 파일 작업을 설치나 로그인 없이 처리하는 웹 도구 모음입니다. 선택한 파일과 입력한 암호는 외부 파일 처리 서버로 보내지 않고 현재 브라우저 안에서 작업합니다.

**바로 사용하기: [worklazy.net](https://worklazy.net/)**

## 사용할 수 있는 도구

### Excel 병합

여러 Excel·CSV 파일을 시트별, 세로 또는 가로 방향으로 합칩니다.

- 파일마다 포함할 시트를 선택하거나 앞에서부터 N개, N번째 시트처럼 범위를 지정
- 수식 보존 또는 값만 복사 선택
- 끝 여백 자르기와 지정 행·열의 SheetTrim 설정
- 암호로 보호된 입력 파일 열기와 결과 XLSX 암호 설정
- XLS·XLSB·XLSM 입력 지원

결과는 XLSX로 저장됩니다. 수식과 서식은 XLSX 입력에서 가장 정확하게 유지되며, XLSM의 매크로는 결과에 보존되지 않습니다.

### Word 비교

수정 전·후 DOCX 문서를 짝지어 본문, 표, 서식, 메모와 머리말·꼬리말 변경을 비교합니다.

- 여러 문서 쌍을 한 번에 비교하고 드래그 또는 좌우 이동으로 짝 구성
- 문서처럼 이어진 좌우 웹 화면에서 삽입·삭제·서식 변경 확인
- 변경 문단만 보기와 전체 내용 보기 전환
- 문서 쌍마다 Excel 비교 보고서 저장
- Word의 검토 탭에서 확인할 수 있는 변경 내용 추적 DOCX 생성

### HWP 편집

HWP·HWPX 문서를 브라우저에서 열어 문서 전체를 편집하고 다시 저장합니다. 파일을 선택하면 도구 영역이 문서 편집 화면으로 전환되며, 문서 처리는 사이트에 포함된 rhwp 편집기에서 이루어집니다.

### HWP 비교

수정 전·후 HWP·HWPX 문서를 여러 쌍으로 비교합니다.

- 문단 안에서 실제로 추가·삭제된 부분을 세밀하게 표시
- 표의 행·열 이동과 삽입을 고려한 구조 비교
- 개요 번호를 포함한 좌우 웹 비교
- 문서 쌍마다 Excel 비교 보고서 저장

### PDF 도구

PDF의 페이지를 눈으로 확인하며 편집·추출하고 다른 형식으로 변환합니다.

- 여러 PDF의 페이지 순서 변경, 선택, 삭제, 90도 회전과 병합
- 선택한 페이지를 한 파일로 저장하거나 여러 범위를 각각 별도 PDF로 저장
- 이미지에서 PDF 만들기 및 PDF 페이지를 PNG·JPG로 변환
- PDF 내용을 DOCX·XLSX·TXT로 변환
- 스캔 문서를 한국어·영어 OCR로 인식해 DOCX·XLSX·TXT 또는 검색 가능한 PDF로 저장

PDF에는 원래 문단·표 구조가 없는 경우가 많아 DOCX와 XLSX 변환 결과의 읽기 순서나 셀 배치는 원본과 다를 수 있습니다. 암호로 잠긴 PDF는 보호를 해제한 사본을 사용해야 합니다.

### 이미지 스튜디오

선택 영역 모자이크·강도 조절 블러를 포함한 단일 이미지 편집부터 여러 파일의 일괄 처리까지 한 화면에서 진행합니다.

- 자르기, 회전, 좌우·상하 반전, 밝기·대비·색조 조절
- 텍스트, 스티커와 도형 레이어 추가 및 테두리·채움 설정
- Delete 키로 선택한 레이어 삭제
- 여러 이미지 일괄 리사이즈와 워터마크 적용
- 세로·가로 이어붙이기와 간격을 직접 지정하는 격자 콜라주
- 여러 프레임으로 GIF 애니메이션 생성
- 단일 편집·일괄 편집·이어붙이기에서 클립보드 이미지 붙여넣기
- PNG·WebP 투명 배경 출력과 JPG 저장 시 흰색 배경 자동 처리

### 비디오 스튜디오

영상 수 제한 없이 계속 추가해 최대 10개 그룹으로 나누어 자르고, 비교 재생하고, 원하는 묶음으로 출력합니다.

- 그룹마다 시작·종료 구간 지정 및 현재 재생 위치를 시작·종료점으로 입력
- 같은 그룹 영상의 동기 재생과 분할 전체화면 비교
- 드래그로 그룹 안의 영상 순서 변경
- 그룹별 개별 저장 또는 순서대로 이어붙이기
- MP4·MKV·WebM 인코딩, GIF 생성, MP3·AAC 음원 추출
- 인코딩 없는 패스스루 자르기
- 작업 중 취소와 완성된 결과의 개별 다운로드·선택형 ZIP 묶기
- MP3·AAC 결과를 오디오 스튜디오 새 탭으로 전달해 계속 편집

대용량 원본은 브라우저 메모리에 통째로 복사하지 않고 읽기 전용으로 연결합니다. 다만 완성된 결과와 변환 중간 데이터는 브라우저 메모리를 사용하므로, 매우 긴 4K 영상은 필요한 구간을 먼저 줄이는 것이 좋습니다. 패스스루 결과가 브라우저의 안전한 출력 한도를 넘을 것으로 예상되면 작업 전에 안내합니다.

### 오디오 스튜디오

MP3·WAV·M4A·AAC·OGG 파일을 파형으로 확인하고 선택 구간을 브라우저 안에서 편집합니다.

- 재생·루프·파형 확대/축소와 밀리초 단위 구간 선택
- 음소거·잘라내기·복사·붙여넣기·삭제와 실행 취소/다시 실행
- 선택 구간의 피치·남성/여성 톤·로봇 음성 효과
- WAV·MP3 내보내기 및 비디오 스튜디오의 추출 음원 이어받기

### 텍스트와 표 데이터

- 공백·줄바꿈·중복 줄 정돈과 Camel·Snake·Kebab·Title Case 변환
- 200개 이상 로컬 정규식 기반 한국어 문장 검토 가이드
- JSON·SQL·XML 들여쓰기, Minify와 문법 오류 확인
- CSV·JSON 객체 배열·HTML Table 상호 변환과 파일 저장

### 근무·시차·급여 계산

- 대한민국 양력·음력·대체공휴일을 반영한 영업일과 예상 연차 계산
- IANA 타임존·서머타임을 반영한 주요 도시 시각과 중복 근무시간 검색
- 최신 기준일을 표시하는 주휴수당·월 실수령액·퇴직금 간이 계산

계산 결과는 일정 계획과 사전 확인을 위한 참고값입니다. 임시공휴일, 회사 규정, 실제 근태·비과세 급여·보험 신고 기준 등에 따라 실제 결과가 달라질 수 있습니다.

### 개인정보·보안·QR

- JPG·PNG의 GPS·촬영 기기·시각 확인 및 EXIF 없는 사본 생성
- `crypto.getRandomValues()` 기반 비밀번호 생성과 강도·공격 시간 추정
- 중앙 로고 QR 코드 PNG 생성과 업로드한 사진의 QR 데이터 스캔
- 이미지 스튜디오 그림판 탭의 연필·붓·지우개·도형·텍스트·Undo/Redo

## 파일 보호 방식

- 파일과 암호는 현재 브라우저 탭 안에서만 사용합니다.
- 문서·영상·이미지를 업로드하는 백엔드 API나 사용자 계정이 없습니다.
- 무거운 작업은 별도 Worker에서 실행하고 작업이 끝나면 종료합니다.
- 탭을 닫거나 새로고침하면 아직 내려받지 않은 작업 내용은 사라집니다.
- 일부 도구는 첫 실행 때 필요한 OCR·문서 처리 실행 파일을 내려받지만, 사용자가 선택한 문서와 결과를 외부로 전송하지 않습니다.

공용 PC에서는 작업이 끝난 뒤 내려받은 파일을 직접 정리해 주세요. 중요한 원본은 수정 전에 별도 사본을 보관하는 것을 권장합니다.
