## 모델 역할 분담 (2026-09-06 사용자 지시)

Codex 는 단계에 따라 모델을 나눠 쓴다. Claude 가 디스패치 프롬프트에 `--model` 로 지정하며, Codex 는 지정된 역할의 기준으로 일한다.

- **반박 라운드(계획·감사 단계) — `gpt-6-astra`.** 계획서·감사 소견에 대한 반박은 astra 가 담당한다. 반박은 "지금 문서가 틀렸는가"에 그치지 말고, **작업 중에 발생하거나 알아챌 예외적인 상황과 구성의 흠결까지 sol 이 감당할 수 있을 정도로 충분히 고려**해 미리 짚는다 — 구현자가 코딩 중에 계획을 재해석해야 하는 지점이 남아 있으면 그것이 이견이다.
- **코딩 단계 — `gpt-5.6-sol`.** 정본화된 계획서·지시서의 구현·수정·테스트는 sol 이 수행한다. 계획에 없는 판단이 필요해지면 임의로 결정하지 말고 보고서에 "범위 밖 발견"으로 남긴다.
- **코딩 완료 후 검수 — `gpt-6-astra`.** sol 의 브랜치 산출물(커밋·검증 출력·기록)을 astra 가 읽기 전용으로 검수하고, 지시서·정본 대비 누락·왜곡·검증 미실행을 증거와 함께 판정한다. 검수 통과가 Claude 게이트 판정의 입력이다.
