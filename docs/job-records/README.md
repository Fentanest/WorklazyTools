# job-records — 작업지시서·검수 보고 스냅샷 (2026-09-20)

이 폴더는 오프라인 관리 대상인 `docs/jobs/`(git 제외)의 **문서(.md)만** 사용자 요청("이번만 git에 올려")으로 추적 위치에 복사한 스냅샷이다. 원본 운영 위치는 여전히 `docs/jobs/todo`·`docs/jobs/archive`이며, 이후 작업 문서는 규칙대로 오프라인에서 관리한다(공통 규칙 「기록·필요한 자료만 읽기」).

- 구조: `todo/`(진행·검토 중 및 2026-09-20 감사 시점의 지시서·보고), `archive/`(완료 판정 문서 15건과 이전 아카이브). 문서 간 상대 링크(`../archive/…`)는 이 구조 안에서 그대로 유효하다.
- 포함: 마크다운 433건(6.5MB). 지시서, 라운드 보고, Astra·Gemini 검수 보고, 완료 감사(`todo/TODO-STATUS-AUDIT-20260920.md`), 마무리 보고(`todo/FINAL-WRAPUP-20260920.md`).
- 제외: PNG·JSON·PDF·로그·node 컴파일 캐시 등 첨부 산출물 약 5,200개(약 280MB) — 재생성 가능하거나 용량이 커 저장소에 넣지 않는다. 문서 안의 `evidence/`, `reports/**/logs`, `shots/` 같은 산출물 링크는 이 스냅샷에서 깨진다(원본 `docs/jobs/`에 보존). `todo/adsense-recheck-20260919/archive/`(2026-09-20 WU3에서 git 추적 해제한 내부 프롬프트·일회성 스크립트 사본 115개)도 제외.
- 개인정보 검사(2026-09-20, Claude): 이메일·전화번호·주민번호·API 토큰·비밀번호 패턴 0건. 한글 이름·주소 문구 "김민수 서울 강남구 테헤란로 123"은 `tests/helpers/pdf-compare-fixtures.mjs`의 합성 fixture 문자열이다. 문서에 나오는 로컬 경로의 계정명은 저장소 커밋 작성자 정보와 같은 범위다.
