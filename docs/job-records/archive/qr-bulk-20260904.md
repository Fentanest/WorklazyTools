## v2 확정 사항 (1차 왕복 8건 — 우선 계약)

1. **QR 생성·스캔 표면**: "기존 워커 직접 재사용" 폐기 — **jsQR(ImageData) 순수 디코더를 공용 추출**해 기존 스캔 워커와 U3 워커가 공유(기존 워커는 요청 ID 없는 단일 응답·함수 미export 실측). 래스터화는 DOM 전용 `drawQr` 재호출이 아니라 **`QRCode.create` 또는 OffscreenCanvas 경로 분리**(브라우저 번들은 create/toCanvas/toDataURL/toString만 — toBuffer 없음 실측). **로고 계약(3차 정정 — 기준 명확화)**: 로고는 정사각으로 **한 변 길이가 QR 이미지 한 변의 최대 22%**(면적 아님 — 기존 단일 생성 구현과 동일 기준)·**로고 사용 시 오류 정정 H 강제**(합성 probe: 22%에서 L 실패·M/Q/H 성공)·흰 보호 영역 포함. 기존 단일 생성 margin 3 회귀 보존, bulk quiet zone은 **기본 4모듈·범위 0~8모듈 정수, 단 로고 사용 시 최소 2모듈 강제**(단위는 QR 모듈 — 재판독 여유 확보). **투명 PNG 재스캔은 흰색 합성 배경 고정**(alpha 실측 근거).
2. **C1·템플릿 계약**: "행 단위 스트리밍" 정정 — **C1 전체 파싱 후 QR 생성 루프만 행 단위**(C1은 전체 버퍼·전체 셀 보유 실측). 매핑은 **열 번호 기준**(이름 아님). **중복 헤더가 템플릿에서 참조되면 실행 전 검증 오류**(중복 해소 미존재 실측 — `{{Name#2}}` 문법 도입 안 함·단순 거부). 치환값은 **`displayValue` 우선**(전화번호·날짜 표시 보존), 기본 파일명 행 번호는 **`sourceRow` 고정**(루프 인덱스 금지).
3. **C2·C3 확장(선행 모듈 작업)**: ① **`SafeZipEntryPath` 신설** — 경로 세그먼트별 기존 C2 규칙 검증 + 전체 경로 NFC/대소문자 충돌 차단(현 C2는 `/`·`\` 거부 실측 — 그룹/폴더 ZIP 경로에 필수) ② **C3에 증분 writer(add/close) 추가** — 즉시 `ZipWriter.add` 방식 retained input 0B vs 배열 방식 payload+archive 동시 보유 실측(10,000건 환산 767MB vs 384MB). 기존 배열 API는 유지(U1·U2 회귀 무영향), 증분 API 병설.
4. **페이로드 계약 실기입(전 유형 생성→jsQR 재판독 왕복 실측 — 한글 UTF-8 보존 확인)**: **(3차 정정) 일반 텍스트 = 입력 원문 그대로(변환·escape 없음·UTF-8) — 7종 완성** / `mailto:<주소>?subject=<UTF-8 percent-encoding>&body=<동일>` / `tel:<입력 원문 유지·선행 + 허용>` / `SMSTO:<번호>:<내용 — 콜론 포함 허용(첫 두 콜론 이후 전부 내용)·개행 유지>` / `WIFI:T:<WEP|WPA|nopass>;S:<SSID>;P:<암호>;H:<true|false>;;` — `\ ; , : "` escape / **vCard 3.0**: CRLF·`VERSION:3.0`·필수 `N`/`FN`·`\\ \, \; \n` escape / URL 유형은 http·https만 허용(그 외 오류 행). escape-heavy 한글 표본(실측 문자열)을 골든 fixture로 고정.
5. **라벨 PDF 산식·preset 실기입(probe 채택)**: pt 단위 — A4 595.28×841.89·Letter 612×792, **margin 36pt·gap 6pt·3열×8행**(경계 실측 exact). 산식: `cellW=(W−2m−(cols−1)gx)/cols`·`cellH=(H−2m−(rows−1)gy)/rows`·`x=m+c(cellW+gx)`·`y=H−m−(r+1)cellH−r·gy`·`page=floor(index/(cols·rows))`. 셀 구성: QR 정사각 fit(상단)·제목/설명 영역(하단 — 제목 1줄·설명 2줄·초과 말줄임).
6. **R4 폰트 공급 확정**: `@pdf-lib/fontkit` 정확 버전 의존 추가(현재 미설치·Helvetica 한글 인코딩 불가 실측). 한글 폰트는 **전용 벤더링 스크립트 + 고정 스냅샷(크기·SHA-256·라이선스 기록)** 방식 — `OFFICE_EDITOR_ASSETS.md`에 폰트 해시표 절 추가(수기 `public/vendor` 추가 금지). 1차 시도: 저장소 내 `rhwp-studio` NotoSansKR WOFF2의 **fontkit WOFF2 지원 실측** — 지원 시 읽기 전용 재사용(생성물 직접 수정 아님 — 참조만), 미지원 시 OFL TTF/OTF 스냅샷 벤더링. **subset 버그 재현 실측 포함**(재현 안 되면 subset, 재현 시 전체 임베드) — 결과를 로드맵 R4에 기록(U4 재사용).
7. **행 상한→예산 체계(성능 실측 기반 — 640px 생성 38ms·재스캔 33ms/건)**: 고정 10,000 폐기 — **예상 출력 바이트 예산**(크기·로고 반영: 소프트 경고 200MB·하드 거부 500MB — 초기값·벤치로 조정 가능 명시) + 행 상한 5,000(하드) + **라벨 PDF 별도 상한 2,400행(100페이지)**. **(3차 정정) 입력 측 한도 신설**: C1이 전체 버퍼·전체 셀 선보유하므로 **입력 파일 ≤50MB·선택 시트 셀 수 ≤2,000,000**(U2 소프트 경고 계약 준용) 초과 시 파싱 전 거부·안내. 1,000행 초과 안내에 **예상 소요 시간 표기**(실측 계수: 생성+재스캔 ≈ 행당 72ms@640px). 개별 PNG는 OPFS 보관·지연 URL — **(3차 정정·4차 문구 교정) OPFS 폴백 계약**: 실행 전 **예상 출력 바이트 대비 사용 가능한 quota가 부족하면** 거부·안내, OPFS 자체 불가 환경은 메모리 Blob 경로로 강등하되 **행 상한 1,000으로 축소**(강등 사실 안내). ZIP은 증분 C3(확정 3항), 취소 시 archive·부분 파일·OPFS 정리.
8. **라우팅·SEO 파일 단위 열거**: `QrMode`에 `"bulk"` 추가·`QrStudioPage({initialMode})`·`QrRoute` wrapper(PdfRoute 패턴, `App.tsx` 2경로), **수동 등록 표면 전부**: `scripts/generate-static-pages.mjs`(route 목록)·`scripts/validate-static-output.mjs`·`src/app/seo.ts`(ko/en title·description·FAQ·social map — 미등록 시 홈 fallback 실측)·`scripts/generate-social-images.mjs`·`tests/unit/seo.test.ts`·사이트맵 검증. **기존 toolRegistry의 QR Studio 카드에 bulk 모드 반영(별도 카드 신설 안 함)**. 완료 기준에 **`npm run test:utilities`**(기존 단일 QR 생성→스캔 회귀 `:270`) 추가.
