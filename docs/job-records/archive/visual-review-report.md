# 시각 검토 보고서 (WorklazyTools 문서 비교 화면)

## 1. 이미지별 파손 목록

**1) `doccmp-desktop.png` (데스크톱 상단)**
- **[확정 건 1] 옵션 스위치 찌그러짐**: '2 결과 형식' 및 '3 비교 범위'의 토글 스위치(웹 비교, Excel 보고서 등)가 정상적인 캡슐 형태가 아닌, 좌우가 잘리고 상하로 찌그러진 왜곡된 얼룩 형태로 렌더링됨.
- **쿠키 배너 가림 현상**: 화면 하단 중앙의 '방문 분석과 광고 사용 설정' 쿠키 배너가 공중에 떠서 스크롤 가능한 본문 영역(옵션 리스트)의 하단을 지속적으로 가리고 있어 시각적으로 답답함.

**2) `doccmp-desktop-scroll.png` (데스크톱 하단 스크롤)**
- **[확정 건 2] 하단 안내문 세로 낙하**: 문서 쌍 비교 영역의 안내 텍스트("수정 전·후 문서를 선택해 주세요.", "HWP 암호는...")가 폭을 잃고 1~2글자 단위로 세로로 길게 낙하하여 레이아웃이 붕괴됨.
- **버튼 및 아이콘 겹침**: '문서 쌍 비교' 파란색 버튼이 비정상적으로 길게 팽창했으며, 그로 인해 좌측의 돋보기 아이콘(`TextSearch`) 영역까지 침범하여 겹쳐서 표시됨.

**3) `doccmp-mobile.png` (모바일 상단)**
- **모바일 쿠키 배너 거대화**: 모바일 화면에서 쿠키 동의 배너가 화면의 거의 절반 가까운 높이를 차지하며 매우 거대하게 렌더링됨.
- **드롭 영역 침범**: 1번 '비교할 문서'의 파란색 클라우드 아이콘 영역 하단이 거대한 쿠키 배너에 의해 가려짐. 하단 GNB 네비게이션('홈', '모든 도구') 위로 배너가 떠 있어 화면이 극도로 좁아 보임.

**4) `doccmp-mobile-scroll.png` (모바일 하단 스크롤)**
- **모바일 스위치 왜곡**: 데스크톱과 동일하게 모바일 뷰에서도 모든 스위치가 찌그러져 있음. 비활성화된 '변경 내용 작성자 통일' 스위치는 회색 얼룩처럼 보임.
- **본문 최하단 잘림 현상**: 하단 고정 네비게이션 바(GNB)의 배경 뒤로 파란색 안내 문구("파일 형식에 맞는 비교 기능을...")가 깔려 들어감. 스크롤을 끝까지 내려도 텍스트가 바에 가려져 완전히 읽을 수 없음.

## 2. CSS 원인 후보 추정 (단서 수준)

최근 진행된 **Shadcn UI (Tailwind v4) 마이그레이션과 기존 레거시 CSS 간의 레이어 충돌(Cascade Conflict)**이 핵심 원인입니다. Tailwind v4 레이어 설정 상 `utilities`가 `legacy`보다 우선순위가 높기 때문입니다.

- **스위치 찌그러짐 원인**: 기존 `.ios-switch` 레거시 CSS(`width: 43px`, `border: 0`, `span`의 `absolute` 위치 등)와 Shadcn의 Tailwind 유틸리티(`w-11`, `h-5`, `border-2`)가 한 요소(`ToggleRow`)에 동시 적용되며 충돌했습니다. 썸네일을 렌더링하는 요소가 legacy의 `absolute` 위치 지정과 유틸리티 크기 지정을 동시에 받아 형태가 파괴되었습니다.
- **세로 텍스트 낙하 및 버튼 팽창 원인**: 기존 `.tool-action-bar`는 자식인 주 버튼 폭을 `width: 190px`로 제한했지만, 신규 `PrimaryButton` 내부에 삽입된 Tailwind `w-full` 클래스가 우선순위를 가져가며 버튼이 100% 폭으로 팽창했습니다. 이로 인해 Flex 컨테이너 내의 텍스트 요소(기존 `min-width: 0` 보유)가 남은 여유 공간을 모두 빼앗겨 최소 폭(1글자)으로 강제 압축된 것입니다.
- **최하단 잘림 및 쿠키 배너 문제 원인**: 고정된 하단 요소(GNB, 쿠키 배너)가 새로 도입되거나 높이가 커졌음에도 불구하고, 본문 스크롤 컨테이너(`.main-content`)의 `padding-bottom`이 이를 반영하지 않아 스크롤 영역이 고정 요소 아래로 깔리는 `z-index` 및 하단 여백 설계 결함입니다.

## 3. 나머지 도구의 유사 파손 개연성 판정

**판정: 100% (매우 높음 / 확정적)**

- 현재 문제가 발생한 `ToggleRow`(스위치)와 `PrimaryButton`, `.tool-action-bar`는 특정 페이지에 종속된 코드가 아닌 **전체 도구에서 공통으로 호출되는 핵심 UI 컴포넌트(`src/components/ui.tsx`)**입니다.
- HWP 비교, Word 비교 등 구조가 동일한 화면은 문서 비교 화면과 똑같이 레이아웃이 붕괴(`tool-action-bar` 세로 낙하)되어 있을 것입니다.
- PDF 도구, Excel 병합·비교 등 설정 옵션이 존재하는 **모든 도구 화면에서 100% 확률로 찌그러진 스위치가 나타나고 있을 것**이며, 본문 하단 여백 잘림 현상 또한 전역 레이아웃 래퍼의 문제이므로 전체 도구에 영향을 미치고 있습니다. 
- **조치 방향**: 전 도구가 오염된 상태이므로 공통 컴포넌트 레벨에서 레거시 CSS 클래스를 즉시 제거하거나 유틸리티 레이어와의 충돌을 격리하는 긴급 핫픽스가 필요합니다.
