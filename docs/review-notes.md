## 2026-10-14 — 이미지→PDF 수명·원본 JPEG 보존 후보

원격 fetch 후 `origin/main=37d67b8` 기준으로 분리했다. 로컬 main의 관련 네 파일은 같은 내용이며 다른 작업의 미커밋 변경은 보존했다. Claude 대화의 PDF/ZIP 공용화·낡은 검사 관문 이력을 참고했다. 갤럭시 당시 로그는 없어 직접 원인은 미확정이다. 확인된 코드 문제는 바이트 확보 없는 상태 등록, 원본 해상도 미리보기, 정상 JPEG까지 재인코딩, 변환 중 입력 변경 허용이었다. 기존 object URL 조기 해제가 실제 원인이었다고 단정하지 않는다. — Codx

Orientation 없음은 저장 픽셀 방향(1)으로 취급한다. 8bit baseline/progressive grayscale/RGB이고 EXIF가 정상이며 ICC/Adobe APP가 없는 JPEG만 직접 삽입한다. Orientation 2–8, 손상 EXIF, CMYK·ICC/Adobe는 브라우저 색상·방향 정규화를 거친다. PNG는 알파를 보존해 정규화한다. 별도의 회전행렬이나 출력 다운샘플링은 추가하지 않았다. 썸네일은 400px·직렬 생성, 표시에는 lazy loading을 적용한다. 헤더/읽기/디코딩 실패는 변환을 막고 썸네일 인코딩·표시 실패만 원본 변환을 허용한다. — Codx

17장 실자료(각 4128×3096 RGB, Orientation 1)는 한 번에/개별 추가 후 최종 PDF의 17개 JPEG 스트림과 원본 SHA-256을 대조했다. 삭제·재추가·재정렬 후 순서도 일치했다. 합성 비대칭 EXIF 1–8/없음은 bitmap/HTMLImage fallback 양쪽의 최종 PDF를 Poppler로 렌더해 모서리 색을 비교했다. PNG SMask, 페이지 크기·A4 여백, 읽기 실패·취소·재시도·이탈·공용 업로더 계약은 별도 자동 검사한다. 사용자 사진·생성 PDF·원시 진단은 gitignored 로컬 작업 증거에만 보관한다. — Codx
